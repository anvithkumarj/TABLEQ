# TableQ 🍽️

TableQ is a Flask-based restaurant ordering and kitchen management system.  
It allows customers to place orders, the kitchen to track active/completed orders, and admins to manage menu items and view sales.

---

## 🚀 Features
- **Customer Page**: Browse menu, place orders.
- **Kitchen Page**: Track active orders, update status, mark completed.
- **Admin Page**: Add/update/delete menu items, view sales stats, reset sales.
- **Sales Tracker**: Shows daily revenue and completed orders.

---

## 🛠️ Tech Stack
- **Backend**: Python, Flask
- **Frontend**: HTML, CSS, JavaScript
- **Database**: In-memory (temporary), can be extended to SQL/NoSQL
- **Version Control**: Git + GitHub
